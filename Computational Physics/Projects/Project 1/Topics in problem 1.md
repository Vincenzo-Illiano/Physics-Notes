# Topics in problem 1

Parent: [[Computational physics projects]]

In Project 1 we study:

- **Discretization of continuous problems**, including derivatives, integration and ODEs; see [[Discretization and numerical differentiation]] and [[Boundary value problems]].
- **Linear systems** of the form $A\mathbf x=\mathbf b$; see [[Matrix equations]].
- **Debugging code**.
- **Counting floating point operations**; see [[Floating point errors and FLOPs]].
- **C++ practice**, including arrays, input/output and timing code.
