# Grading system

Parent: [[Computational physics projects]]

The following grading weights were recorded in the original course notes for projects 3 and 4. They are preserved as course-specific guidance.

| Aspect | Weight |
| --- | ---: |
| Abstract | 1 |
| Introduction | 2 |
| Theory and methods | 4 |
| Code | 4 |
| Results and discussion | 5 |
| Conclusions | 1 |
| References | 1 |
| Overall impression | 2 |

Each aspect is scored from 0 to 5 and a weighted sum is formed. The weights sum to 20, so the unnormalized total ranges from 0 to 100. This does not specify how the course converts that total into a final grade.

## Title

Use a self-contained title that describes the work, rather than a course or assignment label such as “Project 3” or “FYS3150”.

## Abstract

Briefly summarize what the report studies and its main findings. The abstract summarizes the whole work rather than introducing the topic gradually.

## Introduction

Set the stage and motivate the work. End by stating its scope and outlining the rest of the report.

## Theory and methods

Introduce notation and describe the theory and methods. Use a tools subsection as indicated in the original notes. No further guidance for the remaining report sections was included there.
