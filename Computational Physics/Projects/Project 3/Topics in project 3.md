# Topics in project 3

Parent: [[Computational physics projects]]

The main topic is solving [[Initial value problems]]: differential equations with the state specified at an initial time, which is then evolved numerically.

In this project we:

- use the fourth-order [[Runge-Kutta methods|Runge–Kutta method]];
- learn to use classes in C++;
- explore further Eigen functionality.

The physical application is the [[Penning trap]]. Its field configuration and Lorentz force are described in that separate model note.
