Parent: [[Monte Carlo methods]]

**Sampling of random variables** is fundamental in order to use Monte Carlo methods. In particular, we would like to be able to sample a random variable from any given probability distribution ${}p_{X}{}$. 

## Topics
- [[Rejection sampling]]: A useful method to sample random variables from a one dimensional distribution ${}p_{X}{}$.
- [[Inverse transform sampling]]: A method to sample random variables useful when the cumulative probability distribution of the variable is known.
- [[Markov chain Monte Carlo (MCMC)]]: A method to sample random variables from more complex probability distributions using Markov chains.
